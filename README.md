# Gerenciador de Tarefas

Mini projeto em Python criado para praticar lógica de programação e estruturas básicas da linguagem.

## Funcionalidades

- Adicionar tarefas
- Listar tarefas
- Remover tarefas
- Encerrar o programa

## Conceitos praticados

- Funções
- `while`
- `if / elif / else`
- Listas
- `append()`
- `pop()`
- `for`
- `enumerate()`
- `len()`
- Conversão com `int()`
